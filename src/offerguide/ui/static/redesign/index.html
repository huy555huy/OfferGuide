OfferGuide / Redesign v2 · 融合方向 · 2026.05.15

把 dashboard 改回 agent。

现在的 web 端是个传统 SaaS dashboard ── 19 个 page 塞进 5 主 tab + 4 个 dropdown。 但 OfferGuide 真正在做的事是 ambient agent：你睡觉时它在拉牛客 sitemap、扫面经、评估 JD、检测进化候选。 新 UI 必须让 agent 的存在感 永远是第一视觉。

视觉语言

paper + ink Noto Serif SC 显示 single signal red

Asian product 质感 —— 暖纸色底 + 墨色字 + 单一暖橙作"需要决定"的唯一信号色。 中文为主语，字距与留白讲究，标题用 Noto Serif SC 做衬线情绪。

不学 Cursor / Vercel 的 monochrome-with-blue-accent，也不学 Claude warm pastels —— 这是一个长跑代理工具，不是聊天框。

交互语言（融了 daemon 概念）

uptime · wake · budget INTERRUPT [bracket_tag] ⌘ K 命令

Agent 状态像后台进程：顶栏永远有 uptime 14d · wake #47 · $1.24 / 5，主区永远能看到 agent 在跑什么。

决策叫 INTERRUPT —— agent 停下来等你处理，不是产品来"提醒"你。键盘快捷键和命令面板优先。

信息架构：19 → 5（+ 1 抽屉）

/today · /agent · /inbox · /goals · /dashboard
→Mission Control · agent 工作台
/recommended · /jobs · /pipeline · /applications · /funnel
→Pipeline · 推荐池 → 已投 → 面试 → 终态 一条线
/tailor · /project-vault
→Tailor · 简历微调（国内独有的 .docx style 保留 + 反编造护栏）
/interviews · /mock · /reflect · /stories
→Interview · 单岗位备战 workspace
/evolution · /metrics · /portfolio · /debug
→Lab · SKILL self-evolution + dogfood metrics（给面试官看的 wow 区）
/compare · 单 JD 评估弹窗 · BOSS 扩展浮窗
→不是独立 page · 右侧抽屉 + 浏览器扩展浮窗（同一套设计语言）
为什么这次设计能帮你找到工作 · 现在的 README 写得很硬核 —— Anthropic harness primitives / GEPA closed loop / 11 个 evolvable SKILL —— 但跳进 web UI 就被泼一盆冷水：你做的事没在 UI 上呈现。 重设计后，每打开一个屏面试官都能立刻看到 agent 在干什么、为什么这么干、它怎么自我进化。Lab 那一屏单独拿出来就是一份 portfolio piece。
01

每日工作台

打开 OfferGuide 80% 时间在的两个屏。Mission Control 看 agent 干了什么 + 处理 interrupts；Pipeline 看完整投递管线。两个屏都永远不离开 agent 的存在感。
01·a Mission Control 三栏 + agent live rail · INTERRUPTS 中断块 独立打开 ↗
01·b Pipeline 推荐池 → 终态 一条线 · 看板视图 · 拖拽推进 独立打开 ↗
02

单 JD 流程

从看到一个 JD 到准备好面试的完整链路：Drawer 评估（10-20s 出报告） → Tailor 微调简历（反编造 + 保 .docx 段落 style，国内独家）→ Interview 备战（每个项目深挖 + 面经库命中）。每步都让 agent 把推理过程亮出来。
02·a Decision Drawer 右侧抽屉 · 单 JD 评估报告 · 5d prep_plan 独立打开 ↗
02·b Tailor 简历预览 + 建议列表 + anti-fabrication 护栏 独立打开 ↗
02·c Interview Prep 24 道题 + 每个项目深挖大纲 · 弱点标记 独立打开 ↗
03

给面试官看的两屏

Lab 把 OfferGuide 最差异化的能力（SKILL self-evolution 闭环 + Dogfood 真实数据）做成可视化，一屏讲清楚整个项目的硬核之处。Chrome 扩展浮窗展示 agent 是如何陪你在 BOSS 这种真实场景里工作的 —— 决策永远在你这边。
03·a Lab · SKILL 自进化 fitness 演化曲线 + prompt diff + canary 发布 + dogfood 独立打开 ↗
03·b Chrome 扩展浮窗 BOSS JD 页 · 评分 + 写开场白 · 不替你按发送 独立打开 ↗
